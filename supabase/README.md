# ☁️ Supabase Cloud & Configuración

Configuración local e infraestructura como código para la base de datos de **SaidonClub**.

## Responsabilidades
- **Configuración Local**: Define el archivo `config.toml` de Supabase CLI para desarrollo local.
- **Edge Functions**: Almacena las funciones serverless de Supabase (si aplican) para integraciones de terceros.
- **Migrations (Alternativo)**: Configuración que se solapa o complementa con Prisma dependiendo del ciclo de vida del schema.
- Reglas de Storage (RLS) gestionadas a nivel de backend.
