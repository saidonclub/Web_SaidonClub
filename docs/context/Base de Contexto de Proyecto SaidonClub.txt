## 🎯 Decisiones Clave de v5.0

| Tema | Decisión | Justificación |
|------|----------|---------------|
| **Configuration Engine** | 80+ switches configurables | Control total sin deploys. Cada valor de negocio es una entidad auditada |
| **Membresía Preferente** | $39 (antes $29) | +$10 para incluir productos de nutrición básicos |
| **Membresía Pionero** | $129 (antes $97) | +$30~32 para incluir kit premium de nutrición |
| **Productos de membresía** | Obsequio sin puntos ni comisiones | Justifica el valor para quien no está en ciudad con descuentos. Es costo operativo, no margen |
| **Descuentos por ciudad** | Switch `membership_city_discounts_enabled` (default: false) | Feature plus adicional para futura expansión. Apagado inicialmente |
| **Profundidad MLM** | Configurable 1-20 niveles (default: 8) | Permite ajustar el plan sin tocar código |
| **Porcentajes regalías** | Cada nivel tiene su switch | N1=15%, N2=10%, etc. Todo editable |
| **Rangos** | Puntos y bonos configurables por rango | De Plata a Diamante Azul, todo parametrizado |
| **Cierre semanal** | Día y hora configurables | Default viernes 5pm Ecuador, pero cambiable |
