# 🖼️ Paquete Media-Engine

Motor de optimización y manejo de medios para **SaidonClub**.

## Responsabilidades
- **Optimización en tiempo real**: Transforma imágenes subidas por los usuarios/proveedores a formatos modernos (WebP, AVIF) para mejorar el Performance y CLS.
- **Gestión de Storage**: Interfaz unificada para subir, borrar y obtener firmas de URLs seguras desde Supabase Storage.
- **Integración con Next/Image**: Provee las bases para los placeholders (BlurDataURL) y compresión inteligente.

## Dependencias
- Integración principal con los buckets de almacenamiento en la nube.
