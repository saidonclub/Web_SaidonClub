# 📊 Paquete Analytics

Este paquete centraliza el motor de Inteligencia de Negocios (BI) y métricas de **SaidonClub**.

## Responsabilidades
- Análisis de telemetría de ventas del Marketplace.
- Métricas de crecimiento de la red multinivel (MLM).
- Generación de reportes agregados para el Dashboard de Administración (System God).
- Tracking de KPIs y Core Web Vitals (a nivel aplicación).

## Uso
Importado por `apps/web` para alimentar los gráficos de control de negocio.
