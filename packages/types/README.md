# 🏷️ Paquete Types

Repositorio centralizado de tipado TypeScript para todo el monorepo de **SaidonClub**.

## Responsabilidades
- Interfaces y tipos compartidos entre paquetes y aplicaciones.
- Respuestas estándar de la API, estructuras de error forense, y tipos de pago compartidos.
- Extiende la seguridad estática end-to-end garantizando que las firmas de objetos sean idénticas en backend y frontend.
