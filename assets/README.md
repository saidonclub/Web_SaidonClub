# 🎨 Assets Directory

Static assets used across the SaidonClub platform.

## 📁 Structure

- **`/images`**: High-quality product images, marketing banners, and backgrounds.
- **`/icons`**: Custom SVG icons and system symbols.
- **`/fonts`**: Local font files (e.g., Inter, Outfit) for self-hosting.
- **`/branding`**: Logos, favicons, and brand identity assets.

## 🚀 Optimization

- All images are optimized via the `sharp` pipeline in Next.js.
- Prefer **SVG** for icons and illustrations to ensure scalability.
- Use **WebP/AVIF** formats for large images to maximize performance.
