# 🚀 SaidonClub OS v5.2.0 — Changelog
> **Fecha:** 2026-04-23 | **Release:** Minor

## 🌟 Novedades
### 🌍 Soporte Multi-Geográfico
- Implementación de modelos `Country` y `City` en la base de datos.
- Vinculación de usuarios, productos y servicios a ciudades específicas.
- Preparación para filtrado por ubicación y gestión multi-moneda.

### 🗄️ Infraestructura Multi-Schema
- Configuración de Prisma para soportar múltiples esquemas (`public` y `auth`).
- Integración nativa con las tablas de autenticación de Supabase sin conflictos.
- Forzado de compatibilidad con **Prisma v5.12.0** para estabilidad en el pooler de Supabase.

## 🛠️ Mejoras y Refactorización
- **Organización de Raíz:** Categorización formal de todos los archivos de configuración y documentación.
- **Hoja de Ruta:** Actualizada a la Fase 1 (Expansión Global).
- **Consolidación de Tipos:** Tipos compartidos actualizados para soportar geolocalización.

## 🐛 Correcciones (Bug Fixes)
- Corregido error de duplicidad de atributos `@@schema` en el `schema.prisma`.
- Resuelta discrepancia en la URL de conexión del pooler en `.env`.
