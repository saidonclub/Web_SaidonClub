# 📂 Web Utilities (apps/web/utils)

Funciones de utilidad puras, helpers de cliente y configuraciones de SDKs que pueden ser utilizadas tanto en componentes de cliente como de servidor.

## 🛠️ Contenido

- **`supabase/`**: Clientes de Supabase para cliente (browser) y servidor (SSR).
- **`google-maps.ts`**: Configuración y utilidades para la API de Google Maps.

## 💡 Uso
Para operaciones de base de datos desde el navegador, usa `utils/supabase/client.ts`. Para operaciones desde Server Components o Actions, usa `utils/supabase/server.ts`.
