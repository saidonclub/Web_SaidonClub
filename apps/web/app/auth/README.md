# 🔑 Auth Module — SaidonClub Omega OS
> **Sistema de autenticación y gestión de identidad de grado empresarial.**

## 💎 Propósito
Gestión completa del ciclo de vida del usuario: Registro, Login, Recuperación de contraseña y Verificación de correo. Basado en **Supabase SSR** para máxima seguridad.

## 🏗️ Flujos Implementados
- **Login:** Autenticación con email/password.
- **Sign Up:** Registro con validación de datos iniciales.
- **Forgot Password:** Recuperación vía Magic Links / Email.
- **OAuth:** Integración preparada para Google y Apple.

## 🛡️ Seguridad
- **Cookie-Based Auth:** Sesiones seguras mediante cookies `httpOnly`.
- **Zod Validation:** Validación de esquemas en formularios.
- **Rate Limiting:** Protección contra ataques de fuerza bruta.
