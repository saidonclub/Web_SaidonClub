# 📜 Scripts de Mantenimiento y Automatización

Carpeta que contiene herramientas y scripts de DevOps para mantener la integridad de **SaidonClub**.

## Responsabilidades
- **Auditorías**: Scripts como `visual-audit-forense.js` para realizar test de regresión visual con Playwright.
- **Backups**: Scripts (`backup.yml`, o archivos shell/ps1) para orquestar la copia de seguridad de la base de datos y su restauración.
- **Mantenimiento**: Utilidades para corregir imports, resetear la BD y forzar despliegues locales limpios.
