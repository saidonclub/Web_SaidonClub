# 📊 Data Directory

Static datasets, seed files, and configuration payloads.

## 📁 Contents

- **`/seed`**: JSON/TS files for database initialization (Roles, Categories, Initial Products).
- **`/geo`**: Geographical data for shipping and location services (Ecuador specific).
- **`/mock`**: Mock data used for testing and UI prototyping.

## 🛠️ Management

Seed scripts are located in `supabase/seed.sql` and `packages/database/seed.ts`. Use these files to populate the environment.
